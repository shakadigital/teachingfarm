# 🐔 Teaching Farm UB V2.0 - Presentation Guide

## 🎯 **Elevator Pitch (30 detik)**

> **"Teaching Farm UB V2.0 adalah solusi manajemen peternakan ayam petelur pertama di Indonesia yang bekerja 100% offline, dengan pengalaman mobile seperti native app, dan real-time collaboration untuk tim field workers."**

---

## 📱 **Demo Flow untuk Presentasi**

### **1. Opening Hook - Mobile-First Experience (2 menit)**

**🎬 CAPTURE INI:**
- **Buka aplikasi di mobile** → Tunjukkan splash screen dengan logo V2.0
- **Swipe navigation** → Geser kiri-kanan antar halaman dengan smooth animation
- **Pull-to-refresh** → Tarik ke bawah untuk refresh data
- **Haptic feedback** → Tunjukkan getaran saat tap button

**💬 Script:**
*"Lihat betapa mudahnya navigasi dengan satu tangan. Field workers bisa bekerja sambil memegang kandang, cukup swipe untuk pindah halaman. Tidak ada aplikasi peternakan lain yang punya UX semulus ini."*

### **2. Killer Feature - Offline Mode (3 menit)**

**🎬 CAPTURE INI:**
- **Matikan WiFi/data** → Tunjukkan indicator "OFFLINE" muncul
- **Input data harian** → Isi form lengkap, save berhasil
- **Penjualan offline** → Catat transaksi penjualan
- **Nyalakan internet** → Tunjukkan auto-sync dengan progress indicator
- **Cek di dashboard** → Data muncul real-time

**💬 Script:**
*"Ini game changer untuk peternakan di daerah terpencil. Field workers tidak perlu khawatir sinyal lemah. Semua data tersimpan aman offline dan sync otomatis saat ada internet."*

### **3. Real-time Collaboration (2 menit)**

**🎬 CAPTURE INI:**
- **Buka 2 device** → Manager di laptop, Field worker di mobile
- **Input data di mobile** → Field worker input data kandang
- **Lihat update di laptop** → Data muncul real-time dengan notifikasi
- **Manager kirim kas** → Transfer dana ke kandang
- **Notifikasi di mobile** → Field worker dapat notifikasi dana masuk

**💬 Script:**
*"Tim bisa berkolaborasi real-time meski terpisah jarak. Manager di kantor bisa monitor dan kirim dana langsung ke field workers di kandang."*

### **4. Manager Dashboard - Business Intelligence (2 menit)**

**🎬 CAPTURE INI:**
- **Dashboard overview** → Statistik lengkap dengan charts
- **Pembelian management** → Tabel dengan status lunas/belum lunas yang jelas
- **Export laporan** → Download CSV dengan satu klik
- **Kas operasional** → Transfer dana antar kandang

**💬 Script:**
*"Manager punya kontrol penuh dengan dashboard yang powerful. Tracking pembayaran, laporan otomatis, dan manajemen kas yang terintegrasi."*

### **5. PWA Installation Experience (1 menit)**

**🎬 CAPTURE INI:**
- **Install prompt** → Tunjukkan modal V2.0 dengan feature list
- **Install process** → Tap "Install" dan lihat progress
- **Home screen** → App muncul di home screen seperti native app
- **Launch** → Buka dari home screen, full screen tanpa browser

**💬 Script:**
*"Satu tap untuk install, langsung jadi native app. Tidak perlu App Store, tidak perlu update manual. Selalu versi terbaru otomatis."*
