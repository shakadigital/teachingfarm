# 🎬 Teaching Farm UB V2.0 - Demo Script

## 🎯 **Demo Overview (Total: 10 menit)**

**Target Audience:** Pemilik peternakan, Manager, Investor, Tech enthusiasts
**Demo Device:** Smartphone + Laptop (untuk menunjukkan real-time collaboration)
**Internet:** Siapkan WiFi yang bisa dimatikan untuk demo offline

---

## 🚀 **Opening Hook (1 menit)**

### **Script:**
*"Selamat pagi/siang. Saya akan menunjukkan revolusi dalam manajemen peternakan ayam petelur. Berapa dari Anda yang pernah kehilangan data karena field worker lupa mencatat? Atau frustasi karena tidak bisa monitor kandang saat tidak di lokasi?"*

**[Pause untuk response]**

*"Teaching Farm UB V2.0 menyelesaikan semua masalah itu. Ini bukan sekedar aplikasi, ini adalah transformasi digital untuk peternakan Indonesia."*

### **Action:**
- Tunjukkan smartphone dengan app sudah terbuka
- Highlight logo V2.0 di header

---

## 📱 **Demo 1: Mobile-First Experience (2 menit)**

### **Script:**
*"Pertama, lihat betapa mudahnya navigasi. Field worker bisa bekerja dengan satu tangan sambil memegang kandang."*

### **Actions to Demonstrate:**
1. **Swipe Navigation**
   - Geser kiri-kanan antar halaman
   - Tunjukkan smooth animation
   - *"Swipe kiri untuk halaman berikutnya, kanan untuk sebelumnya"*

2. **Pull-to-Refresh**
   - Tarik ke bawah di halaman dashboard
   - Tunjukkan loading animation
   - *"Tarik ke bawah untuk refresh data terbaru"*

3. **Haptic Feedback**
   - Tap beberapa button
   - Minta audience merasakan getaran
   - *"Setiap aksi ada konfirmasi getaran, jadi field worker tidak perlu selalu lihat layar"*

### **Key Message:**
*"Tidak ada aplikasi peternakan lain yang punya user experience semulus ini. Didesain khusus untuk kondisi lapangan."*

---

## 🌐 **Demo 2: Offline Capability - The Game Changer (3 menit)**

### **Script:**
*"Sekarang fitur yang paling revolusioner - mode offline 100%. Mari kita simulasikan kondisi di kandang dengan sinyal lemah."*

### **Actions to Demonstrate:**

1. **Matikan Internet**
   - Turn off WiFi/mobile data
   - Tunjukkan indicator "OFFLINE" muncul
   - *"Lihat, app langsung detect tidak ada internet dan masuk mode offline"*

2. **Input Data Harian (Offline)**
   - Buka halaman Input Harian
   - Isi form lengkap: telur, pakan, mortalitas
   - Save data
   - *"Semua data tersimpan aman di device, tidak ada yang hilang"*

3. **Catat Penjualan (Offline)**
   - Pindah ke halaman Penjualan
   - Input transaksi penjualan
   - Save berhasil
   - *"Field worker bisa catat penjualan langsung ke pelanggan tanpa khawatir sinyal"*

4. **Nyalakan Internet & Auto-Sync**
   - Turn on WiFi/mobile data
   - Tunjukkan sync progress indicator
   - *"Begitu ada internet, semua data sync otomatis"*
   - Wait for sync complete notification
   - *"Data sudah aman di cloud dan bisa diakses semua tim"*

### **Key Message:**
*"Ini game changer untuk peternakan di daerah terpencil. Zero data loss, 100% reliability."*

---

## ⚡ **Demo 3: Real-time Collaboration (2 menit)**

### **Script:**
*"Sekarang saya akan tunjukkan bagaimana tim bisa berkolaborasi real-time meski terpisah jarak."*

### **Setup:**
- Smartphone (sebagai Field Worker)
- Laptop (sebagai Manager)
- Buka kedua device dengan user berbeda

### **Actions to Demonstrate:**

1. **Field Worker Input Data**
   - Di smartphone, input data kandang baru
   - Save data
   - *"Field worker di kandang input data..."*

2. **Manager Lihat Update Real-time**
   - Di laptop, tunjukkan data muncul langsung
   - Highlight notifikasi real-time
   - *"Manager di kantor langsung lihat update tanpa refresh"*

3. **Manager Kirim Kas**
   - Di laptop, buka fitur Kirim Kas
   - Transfer dana ke kandang
   - *"Manager kirim dana operasional..."*

4. **Field Worker Terima Notifikasi**
   - Di smartphone, tunjukkan notifikasi dana masuk
   - Cek saldo kas bertambah
   - *"Field worker langsung dapat notifikasi dana masuk"*

### **Key Message:**
*"Koordinasi tim jadi efisien. Manager punya kontrol penuh, field worker dapat support real-time."*

---

## 💼 **Demo 4: Manager Dashboard & Business Intelligence (1.5 menit)**

### **Script:**
*"Untuk level management, tersedia dashboard yang powerful untuk business intelligence."*

### **Actions to Demonstrate:**

1. **Dashboard Overview**
   - Tunjukkan charts dan statistik
   - Highlight key metrics
   - *"Semua KPI dalam satu layar - produksi, penjualan, kas"*

2. **Pembelian Management**
   - Buka tabel pembelian
   - Tunjukkan status lunas/belum lunas dengan color coding
   - *"Tracking pembayaran supplier dengan visual yang jelas"*

3. **Export Laporan**
   - Klik tombol Download
   - Tunjukkan file CSV ter-download
   - *"Laporan otomatis, tidak perlu Excel manual"*

### **Key Message:**
*"Manager punya kontrol penuh dengan data yang akurat dan real-time."*

---

## 🎯 **Demo 5: PWA Installation Experience (0.5 menit)**

### **Script:**
*"Terakhir, cara install yang revolusioner - tidak perlu App Store."*

### **Actions to Demonstrate:**

1. **Install Prompt**
   - Trigger install prompt (jika belum muncul)
   - Tunjukkan modal V2.0 dengan feature list
   - *"Satu tap untuk install, langsung jadi native app"*

2. **Install Process**
   - Tap "Install"
   - Tunjukkan progress
   - *"Tidak perlu download dari App Store, langsung dari browser"*

3. **Home Screen Access**
   - Tunjukkan app icon di home screen
   - Launch dari home screen
   - *"Akses langsung dari home screen, full screen tanpa browser"*

### **Key Message:**
*"Cross-platform, auto-update, selalu versi terbaru. Satu solusi untuk semua device."*

## 🎬 **Demo Backup Plans**

### **Jika Internet Bermasalah:**
- Gunakan hotspot mobile sebagai backup
- Siapkan video recording demo offline
- Focus ke fitur yang tidak perlu internet

### **Jika Device Bermasalah:**
- Siapkan 2 smartphone backup
- Gunakan browser desktop untuk demo mobile (responsive)
- Siapkan screenshot sequence sebagai fallback

### **Jika Audience Skeptis:**
- Siapkan comparison chart dengan kompetitor
- Tunjukkan ROI calculator
- Berikan testimoni dari beta users

---

## 💡 **Pro Tips untuk Presenter**

### **Body Language:**
- Pegang device dengan confident
- Gesture yang natural saat swipe
- Eye contact dengan audience, bukan screen

### **Pacing:**
- Slow down saat demo teknis
- Pause setelah key points
- Allow time untuk audience absorb

### **Interaction:**
- Ajak audience coba swipe gesture
- Minta feedback tentang UX
- Encourage questions during demo

### **Technical:**
- Test semua demo flow sebelum presentasi
- Charge device 100%
- Clear browser cache untuk performance optimal
- Siapkan data dummy yang realistic

---

## 🎯 **Audience-Specific Adaptations**

### **Untuk Pemilik Peternakan:**
- Focus pada ROI dan cost savings
- Emphasize reliability dan data security
- Tunjukkan ease of use untuk staff

### **Untuk Tech Audience:**
- Highlight PWA technology

### **Untuk Investor:**

- Highlight competitive advantages
- Discuss monetization strategy

### **Untuk End Users:**
- Emphasize ease of use
- Show real-world scenarios
- Demonstrate immediate benefits
